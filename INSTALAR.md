# Como instalar

1. Descarrega o projeto (ZIP do GitHub)
2. Extrai o ZIP
3. Abre o browser → `chrome://extensions`
4. Ativa **Modo de programador**
5. **Carregar sem compactação** → escolhe a pasta **`extension`**
6. Vai à Twitch e dá **F5**

Pronto. A extensão reclama a caixinha verde automaticamente.
